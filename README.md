# v2rayNG Auto Downloader

یک صفحه وب ساده برای دانلود خودکار آخرین نسخه v2rayNG از GitHub

## ✨ ویژگی‌ها

- دریافت خودکار آخرین نسخه پایدار v2rayNG
- نمایش تاریخ انتشار و توضیحات هر نسخه
- نمایش همه فایل‌های APK هر نسخه: Universal، ARM64، ARM32، x86 و x86_64
- تفکیک فایل‌های معمولی و F-Droid و نمایش نام و اندازه فایل
- نمایش حداکثر ۱۰۰ ریلیز اخیر با امکان نمایش نسخه‌های آزمایشی
- انتخاب دستی معماری در صورت نبود Universal؛ بدون دانلود خودکار فایل نامناسب
- دریافت مستقل آخرین نسخه پایدار، حتی وقتی ریلیزهای اخیر همگی آزمایشی هستند
- طراحی واکنش‌گرا و سازگار با موبایل
- شمارش معکوس قابل لغو برای دانلود خودکار Universal معمولی
- پشتیبانی از فونت فارسی (وزیرمتن)

## 🚀 نحوه استفاده

1. صفحه را در مرورگر باز کنید
2. سیستم به صورت خودکار آخرین نسخه را پیدا می‌کند
3. می‌توانید:
   - منتظر بمانید تا دانلود خودکار شروع شود (10 ثانیه)
   - یا دکمه دانلود را فورا کلیک کنید
4. اگر Universal موجود نباشد، فایل متناسب با معماری دستگاه را انتخاب کنید:
   - ARM64: بیشتر گوشی‌های جدید
   - ARM32: گوشی‌های قدیمی ۳۲ بیتی
   - x86 / x86_64: دستگاه‌ها یا شبیه‌سازهای Intel
   - اگر معماری را نمی‌دانید، مشخصات دستگاه را بررسی کنید؛ انتخاب بر اساس مرورگر قابل اعتماد نیست.
5. برای مشاهده فایل‌های هر نسخه، بخش «نسخه‌های قبلی و آزمایشی» را باز کنید.
6. با پارامتر `?version=1.2.3` یک نسخه مشخص را باز کنید. تطبیق تگ دقیق است و به ۱۰۰ ریلیز اخیر محدود نیست.

دانلود خودکار فقط برای Universal معمولی انجام می‌شود؛ باز کردن انتخاب فایل‌ها یا نسخه‌های قبلی، یا دکمه «لغو»، تایمر را متوقف می‌کند. فایل‌های امضا (`.apk.sig`) در لیست دانلود APK نمایش داده نمی‌شوند.
